# Datasets Used

This folder contains the datasets used for evaluating the semantic similarity-based plagiarism checker.

Datasets:
- MNLI
- MRPC
- QQP
- STS-B
- PAWS
- MS MARCO
- PubMedQA
- SciDocs
- SciFact
- SNLI
- ANLI
- FEVER
- PAWS-X
- WikiQA
- ArguAna
- NFCorpus
- FiQA-2018
- TREC-COVID

Refer to docs/dataset_information.xlsx for dataset formats and source links.
